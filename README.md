## 🚀 How to Run Locally

### Option 1: Double-Click
Simply double-click `index.html` to open it in any modern web browser (Google Chrome, Microsoft Edge, Firefox, Brave, Safari).

### Option 2: Local HTTP Server
Run with Python:
```bash
python -m http.server 8080
```
Then navigate to `http://localhost:8080`.
